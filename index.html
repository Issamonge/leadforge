Why this closes the loop (and what a calendar can't do)

A calendar only reminds you to act — it produces nothing. This engine produces a stream of buyers, a pitch delivered to each, and a live payment link they can pay the instant they're convinced. You are no longer the bottleneck for finding and pitching. You remain the bottleneck only for delivery and complex negotiations — and the WhatsApp alert tells you exactly when that is.

How this runs while you sleep

  1. Free data sources — n8n & Make.com community boards, Hacker News "Who is hiring", RemoteOK, Remotive. No API keys.
  2. Scheduled engine — a GitHub Action runs engine/run.mjs daily, scores leads, and commits fresh data.
  3. This dashboard — hosted free (GitHub Pages / Vercel / Cloudflare Pages), reads the committed data.
  4. Digest email — optional: add a free Resend API key and the engine emails you the day's pipeline.
  5. You only step in — log into Upwork/marketplaces, take calls, close deals.
